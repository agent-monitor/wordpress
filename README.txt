== Description ==

**Over 60% of your website's traffic isn't human — and conventional analytics can't see any of it.**

Agent Monitor helps you understand how AI agents, crawlers, and scrapers interact with your website. By tracking these non-human visitors, you can gain insights into how your site is being indexed, analyzed, and used by automated systems. Our dashboard provides detailed analytics on which agents are visiting, what pages they access, and how frequently they return.

This plugin connects your WordPress site to the Agent Monitor service. You will need a free account and an access token to begin collecting data.

= What you get =

* **Real-time AI & bot traffic** — see human vs. AI vs. other bot traffic split as it happens.
* **Bot & agent breakdown** — identify exactly which agents are visiting (GPTBot, ClaudeBot, PerplexityBot, Google-Extended, and more) and which company operates each one.
* **URL Inspector** — check any single page: has AI visited it, how recently, how often, and did it send you any real human visitors afterward?
* **AI Citations** — see which of your pages ChatGPT and other assistants actually fetch and cite when answering user questions, so you know what's working and can scale it.
* **Top pages by AI traffic** — a ranked view of the pages agents and crawlers visit most.
* **Cookie-less, server-side collection** — data is captured server-side, so it isn't blocked by ad blockers or affected by cookie consent.
* **No credit card required** — start on the free plan and see your real AI traffic volume before committing to anything.

= Why site owners use Agent Monitor =

* Know whether AI assistants can even find your new content — instead of finding out weeks later when traffic quietly disappears.
* Understand how much of your "traffic" is actually crawlers and scrapers, and where it's concentrated.
* Get a real, transparent classification of agents based on how they behave — not a black-box AI guess.
* Built and battle-tested inside a working SEO agency (Top Online) on real client sites, not as a side project.

1. Create a free Agent Monitor account.

== Frequently Asked Questions ==

= Is Agent Monitor free? =

Yes. The free plan includes up to 100,000 events per month, one website, and a multi-week data exploration window — no credit card required. Paid plans add more events, more sites, longer data windows, and priority support.

= Do I need an Agent Monitor account? =

Yes. The account is where you view your dashboards, bot breakdowns, URL Inspector, and AI Citations reports. Creating one is free and takes about a minute.

= Does this plugin block AI bots? =

No. Agent Monitor is an analytics and visibility tool — it shows you what's already happening on your site so you can make informed decisions. It does not modify robots.txt or block any traffic.

= Will this slow down my site? =

No. Data is sent to Agent Monitor after WordPress has already finished processing the request, in a non-blocking way, so it doesn't add to page load time for your visitors.

= Is any data sent without my consent? =

No. Nothing is sent to Agent Monitor until you enter your access token and enable data collection on the plugin's settings page.

= Which AI agents and bots does it track? =

Agent Monitor tracks all bot traffic, focusing on known AI crawlers and assistant agents such as GPTBot, ChatGPT-User, ClaudeBot, PerplexityBot, Google-Extended, and others, and classifies them by operator and purpose.

== Installation ==

1. Install and activate the Agent Monitor plugin from the WordPress Plugin Directory.
2. [Sign up](https://app.agentmonitor.io) for a free Agent Monitor account and create a new site.
3. Copy your site's access token from the [integration page](https://app.agentmonitor.io/integrate).
4. Go to the plugin's settings page in your WordPress admin, paste the token, and save.
5. Wait a few moments for traffic data to start appearing in your Agent Monitor dashboard.

== External services ==

This plugin sends visit data to the Agent Monitor service so you can analyze your site's AI agent and bot traffic. It sends relevant visit data to Agent Monitor after each request has been processed by WordPress, in a non-blocking way that does not slow down page loads for your visitors.

No data is sent unless you explicitly enter your Agent Monitor access token on the plugin's configuration page and enable data collection.
